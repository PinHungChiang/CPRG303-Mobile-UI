# CPRG-303 — Building a Mobile UI with Expo and React Native

This project recreates the **Instagram group profile sample** supplied in the assignment using React Native + Expo + TypeScript. It uses `View`, `Text`, `Image`, `Pressable`, `ScrollView`, `SafeAreaView`, `Alert`, and `StyleSheet`.

## Required assignment behavior

- Mobile UI visually follows the sample group-profile layout.
- Local comparable images are used instead of the original sample images.
- The **Alert** button appears at the bottom.
- Pressing **Alert** displays: `Alert Button pressed`.

## Run

```bash
npm install
npx expo start
```

Then:
- press `w` for web
- press `i` for iOS Simulator on macOS with Xcode installed
- press `a` for Android Emulator with Android Studio configured
- or scan the QR code with Expo Go on a physical phone
